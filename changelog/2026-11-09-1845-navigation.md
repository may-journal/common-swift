### 2026.11.09.1845

> An app moves between screens, guards unsaved work and draws in its own tokens with shared Navigation and Theme packages.

- Feat: `Router` owns a stack's path and `RoutedStack` binds a `NavigationStack` to it; `DeepLinkTable` reads links through one parser per host.
- Feat: `PendingOpen` holds a cold-launch request until the screen takes it once.
- Feat: `LeaveGuard` asks Save, Discard or Cancel before an exit drops unsaved work, and a reset mid-save cancels the leave.
- Feat: `Theme` hands the app's palette, type, spacing and radii to shared views; each color builds from a 0xRRGGBB value, light and dark.
- Docs: requirements 0001 to 0005, the architecture views, the navigation and theme lessons and the README.
