### 2026.11.11.0240

> An app depends on common-swift by its URL and one version tag, and picks only the products it uses.

- Feat: the root `Package.swift` lists the Storybook and StorybookSandbox products by path, so a URL dependency resolves them with no copied source.
- Feat: an app that links only Storybook leaves StoreKit out, since the sandbox gate stays a product of its own.
- Docs: the README says how an app depends on the repo, and each package still builds alone from its own manifest and tests.
- Test: 0009's tests build an app against a tagged clone and fail when otool lists nothing; one root `.gitignore` covers each package.
